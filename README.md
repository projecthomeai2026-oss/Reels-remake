# Reels-remake bot

Telegram-бот на aiogram, который принимает видео и превращает его в
вертикальный клип формата Reels (9:16): ffmpeg вписывает кадр в 1080x1920
с размытым фоном, Remotion накладывает подпись (если она есть у видео),
faster-whisper распознаёт речь и выжигает субтитры, Giphy добавляет
гифку в угол кадра, а в конце подмешивается одна из встроенных фоновых
музыкальных дорожек.

## Запуск

1. Установите Python-зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Убедитесь, что в системе установлен `ffmpeg` (доступен в `PATH`).

3. Установите зависимости Remotion (нужен Node.js):

   ```bash
   cd remotion && npm install && cd ..
   ```

4. Скопируйте `.env.example` в `.env` и укажите токен бота и (опционально)
   ключ Giphy — без него шаг с гифками просто пропускается:

   ```bash
   cp .env.example .env
   ```

5. Запустите бота:

   ```bash
   python -m bot.main
   ```

## Как это работает

- Пользователь отправляет боту видео (можно с подписью).
- Бот скачивает файл и вписывает его в вертикальный холст 1080x1920:
  исходный кадр не обрезается, а центрируется поверх размытой увеличенной
  копии самого себя, которая заполняет свободное пространство сверху/снизу
  (`bot/services/video_processor.py`). Длительность ограничивается
  (`bot/config.py`, `MAX_DURATION_SECONDS`).
- Если у видео есть подпись (caption), она накладывается текстом поверх
  ролика через Remotion-композицию `remotion/src/ReelsCaption.tsx`
  (`bot/services/remotion_renderer.py`).
- Речь в видео распознаётся через faster-whisper и выжигается как
  субтитры (`bot/services/subtitles.py`). Если речи нет — этот шаг
  просто пропускается.
- В правый верхний угол добавляется гифка с Giphy — по подписи к видео
  как поисковому запросу, либо случайная из небольшого набора реакций
  (`bot/services/gif_overlay.py`). Требует `GIPHY_API_KEY`; без ключа
  шаг пропускается.
- Поверх подмешивается одна из фоновых дорожек из `assets/music/`
  (`bot/services/music.py`); если у видео уже была своя дорожка, она
  не заглушается, а сводится вместе с музыкой.
- Готовый клип отправляется обратно пользователю.

## Известное ограничение

При наложении сразу и подписи (Remotion), и субтитров (whisper) обе
надписи позиционируются независимо у нижнего края кадра — на видео с
длинным текстом в обоих слоях они могут визуально пересечься.
