# Reels-remake bot

Telegram-бот на aiogram, который принимает видео и превращает его в
вертикальный клип формата Reels (9:16) с помощью ffmpeg, а если видео
прислано с подписью — накладывает эту подпись как текст поверх ролика
через Remotion.

## Запуск

1. Установите Python-зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Убедитесь, что в системе установлен `ffmpeg` (доступен в `PATH`).

3. Установите зависимости Remotion (нужен Node.js):

   ```bash
   cd remotion && npm install && cd ..
   ```

4. Скопируйте `.env.example` в `.env` и укажите токен бота:

   ```bash
   cp .env.example .env
   ```

5. Запустите бота:

   ```bash
   python -m bot.main
   ```

## Как это работает

- Пользователь отправляет боту видео (можно с подписью).
- Бот скачивает файл и вписывает его в вертикальный холст 1080x1920:
  исходный кадр не обрезается, а центрируется поверх размытой увеличенной
  копии самого себя, которая заполняет свободное пространство сверху/снизу
  (`bot/services/video_processor.py`). Длительность ограничивается
  (`bot/config.py`, `MAX_DURATION_SECONDS`).
- Если у видео есть подпись (caption), она накладывается текстом поверх
  ролика через Remotion-композицию `remotion/src/ReelsCaption.tsx`
  (`bot/services/remotion_renderer.py`).
- Готовый клип отправляется обратно пользователю.
